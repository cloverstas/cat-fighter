# SourceArt — исходники

Оригиналы из AI-генераций (ChatGPT, ElevenLabs и т.д.) до обработки.
Unity эту папку не видит (она вне `Assets`), git — хранит.

| Папка | Что внутри | Во что превращается |
|---|---|---|
| `Murzik/`, `Belchik/` | листы анимаций `*_sheet.png` | `python Tools/slice_sprites.py murzik` → `Assets/Art/Murzik/` |
| `Shared/` | блок и присед — оба кота на одном листе | тот же скрипт, `pick` 0/1 |
| `UI/` | портреты, рамки, логотипы, раунды, экран итогов | обрезка и уменьшение до 1024 px → `Assets/Art/UI/` |
| `Audio/` | звуки с исходными именами | обрезка тишины, моно, `.ogg` для музыки → `Assets/Audio/` |
| `Concept/` | заставка-концепт, с которой начался проект | — |

Новые листы кладём сюда, добавляем в `CHARACTERS` в `Tools/slice_sprites.py`,
режем скриптом и жмём в Unity **Cat Fighter → Настроить бойцов**.
