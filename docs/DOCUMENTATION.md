# Cat Fighter — документация

2D-файтинг про домашних котов: **Мурзик** (серый полосатый, «Street Legend») против **Бельчика** (белый, «Pure Paws»).
Играется в браузере на ПК и телефоне: **https://cloverstas.github.io/cat-fighter/**

Документ описывает, как устроена игра, откуда берётся графика и звук, как собирать и выкладывать, и какие подводные камни уже найдены.
План уменьшения размера сборки — в [OPTIMIZATION_PLAN.md](OPTIMIZATION_PLAN.md).

## 1. Игра

### Ход матча

```
ВЫБЕРИ БОЙЦА  →  ROUND N  →  FIGHT!  →  бой (таймер 99 с)  →  K.O.! / TIME!  →  +лапка победителю
                     ↑                                                              │
                     └──────────── следующий раунд, пока кто-то не наберёт 2 победы ─┘
                                                                                    ↓
                                                             ПОБЕДА! / ПОРАЖЕНИЕ! + счёт + «ЕЩЁ РАЗ»
```

- Игрок выбирает кота; выбранный всегда стоит **слева** лицом вправо, противник (ИИ) — справа.
- Раунд выигрывается нокаутом или по таймеру (у кого больше здоровья; поровну — ничья, раунд переигрывается).
- Матч — до `roundsToWin` побед (2 в игре, 1 — для короткой рекламной версии).

### Управление

| ПК | Телефон (экранные кнопки) | Действие |
|---|---|---|
| A / D, ← / → | ◀ ▶ (держать) | шаг (приставной, назад — те же кадры задом наперёд) |
| I | ЛАПА (левая кнопка) | удар левой лапой |
| O | ЛАПА (правая кнопка) | удар правой лапой |
| J | НОГА | удар ногой |
| K | СУПЕР (светится при полной шкале) | суперудар |
| Пробел (держать) | БЛОК (держать) | блок |
| S (держать) | ▼ (держать) | присед |

Экран выбора: A / D + Пробел или Enter, либо клик/тап по коту.
Телефон держат горизонтально; в вертикальном положении игра ставится на паузу с надписью «ПОВЕРНИ ТЕЛЕФОН».

### Боевая система

| Действие | Урон | Особенности |
|---|---|---|
| Удар лапой | 8 | противник только морщится (`hit_light`) и чуть отъезжает; от лапы нельзя пригнуться |
| Удар ногой | 15 | сбивает с ног (`hit` — падение и подъём); **от пинка можно пригнуться** |
| Суперудар | 30 | рывок вперёд, **не блокируется и не уворачивается**, сбивает с ног |
| Блок | — | проходит 20% урона (минимум 1), отталкивает назад |
| Присед | — | пинок (и всё, что `canBeDucked`) проходит над головой — 0 урона |

- **Кадр попадания**: урон засчитывается не при нажатии, а на конкретном кадре анимации (лапа вытянута). Удар «долетает», если противник впереди и ближе дальности удара (`punchReach` 3.2, `kickReach` 3.7, `superReach` 4.3).
- **Шкала супера** копится: ×1.2 от нанесённого урона и ×0.8 от полученного (шанс отыграться). Полная (100) — можно бить суперударом.
- **Суперудары**: у Мурзика — «Уширо с разворота» (огненный, с разворотом на 360°), у Бельчика — «Белый вихрь» (капоэйра, стойка на лапах, ледяной вихрь).
- **ИИ** (`FighterAI`) в два слоя: *защита* — на начатую атаку игрока с шансом ставит блок или пригибается от пинка; *нападение* — подходит, раз в 0.35–0.9 с решает: бить (шанс `aggression`), отойти или ждать; при полной шкале и в досягаемости с шансом бьёт суперударом. Случайность — чтобы не был предсказуемым роботом.

### «Сочность» (game feel)

- Портрет в HUD морщится, вздрагивает и вспыхивает красным при пропущенном ударе.
- Полоска здоровья: зелёная убывает сразу, жёлтый «шлейф» догоняет с задержкой (видно, сколько сняли).
- Нокаут: замедление времени ×0.3, логотип K.O.!
- Суперудар: стоп-кадр, фон темнеет, при попадании — белая вспышка, тряска камеры, стоп-кадр (hitstop).
- Атакующий рисуется поверх противника (`sortingOrder`), чтобы лапа/нога ложилась **на** него.
- Звук: свист замаха, лёгкий/тяжёлый удар, блок, свой голос боли и свой боевой клич у каждого кота; случайный вариант звука и ±8% высоты тона.

## 2. Архитектура кода

Главная идея — **разделение «тело / руки / мозг»**: боец ничего не знает о том, кто им управляет.

```
             ┌─────────────────────┐        ┌───────────────────┐
             │ PlayerController    │        │ FighterAI         │
             │ (клавиатура + тач)  │        │ (решения, шансы)  │
             └─────────┬───────────┘        └─────────┬─────────┘
                       │   Move / Attack / HoldStance / TrySuper   │
                       └──────────────┬────────────────────────────┘
                                      ▼
                             ┌─────────────────┐   Play / Hold / PlayLoop
                             │ Fighter (тело)  │ ─────────────────────────▶ SpriteFramePlayer
                             └────────┬────────┘ ◀──── событие HitFrame ───
                                      │ события: Hurt, KnockedOut, AttackStarted,
                                      │          Blocked, Dodged, SuperStarted, SuperLanded
             ┌────────────────┬───────┴─────────┬─────────────────┐
             ▼                ▼                 ▼                 ▼
       RoundManager       BattleHUD        SoundManager      SuperEffects
       (судья)            (интерфейс)      (звук)            (кино-эффекты)
```

Благодаря этому выбор бойца — это просто перестановка компонентов `PlayerController` / `FighterAI`, а тач-управление — ещё один источник ввода в `PlayerController`. `Fighter` при этом не меняется.

### Скрипты игры (`Assets/Scripts`)

| Скрипт | Что делает |
|---|---|
| `Fighter` | «Тело»: здоровье, движение (с подскоком или анимацией ходьбы), стойки (`Stand/Block/Crouch`), атаки, получение удара (`TakeHit(HitInfo)` → сколько урона прошло), шкала супера, рывок супера, нокаут, `Freeze/Unfreeze/ResetForRound`. Команды: `Move`, `Attack`, `HoldStance`, `TrySuper`. |
| `PlayerController` | «Руки игрока»: клавиатура + `TouchControls` → команды `Fighter`. |
| `FighterAI` | «Мозг компьютера»: защита (блок/присед на атаку) и нападение (подход, удары, отступ, супер). Характер — ползунками в Inspector. |
| `SpriteFramePlayer` | Свой проигрыватель покадровой анимации вместо Animator: клипы (имя, кадры, FPS, кадр попадания), `Play` (разово, опционально «замереть на последнем кадре»), `PlayLoop` (ходьба, в т.ч. задом наперёд), `Hold` (поза блока/приседа), событие `HitFrame`. Может собирать клипы из кадров других клипов (`hit_light`, `ko` собираются из `hit`). |
| `IdleBreathing` | «Дыхание» в стойке масштабом (синусоида) вместо кадров. |
| `RoundManager` | «Судья»: ждёт экран выбора (`IEnumerator Start`), раунды, таймер, счёт, нокаут с замедлением, конец матча. Сам не рисует — командует `BattleHUD`. |
| `CharacterSelect` | Экран «ВЫБЕРИ БОЙЦА»; раздаёт роли и места, запоминает прошлый выбор. |
| `BattleHUD` | Весь интерфейс боя строится из кода: портреты в рамках, полоски здоровья со шлейфом, таблички, таймер, лапки-счёт, шкалы супера, баннеры, вспышка, экран итогов с пульсирующей кнопкой (CTA). |
| `SuperEffects` | Кино-эффекты суперудара: стоп-кадр, затемнение фона, вспышка, тряска камеры, hitstop. |
| `SoundManager` | Музыка + эффекты по сигналам (`Cue`), пул из 6 источников, случайный вариант и высота тона, личные звуки котов. |
| `ArenaBackground` | Фон-комната на весь экран с привязкой нарисованного пола к полу котов; кадрирование камеры (на телефоне ближе — коты крупнее); лёгкое затемнение. |
| `TouchControls`, `TouchButton` | Экранные кнопки (круги и стрелки рисуются кодом), только на мобильных; пауза «поверни телефон». |
| `GameUI`, `AdaptiveScaler` | Общий шрифт с кириллицей (Russo One из `Resources/Fonts`); масштаб интерфейса под пропорции экрана. |

### Инструменты редактора (`Assets/Editor`)

| Скрипт | Что делает |
|---|---|
| `FighterSetup` | Меню **Cat Fighter → Настроить бойцов**: для каждого кота заполняет клипы из `Assets/Art/<Имя>` (кадры, FPS, кадр попадания, необязательные `walk`/`super`/`win`), позы блока/приседа, портреты, таблички, голоса; связывает противников; вешает `PlayerController`/`FighterAI`; настраивает камеру, фон, `RoundManager` + `BattleHUD` + звук + тач-кнопки. Запускать можно сколько угодно раз. |
| `ArtImportSettings` | Всё, что попадает в `Assets/Art`, автоматически становится спрайтом: Single, pivot `(0.5, 0.03)` — между лап, 100 px/ед., mip-карты, трилинейная фильтрация. Поднять `GetVersion()` — Unity переимпортирует все картинки. |
| `WebGLBuild` | Меню **Cat Fighter → Собрать WebGL** (`Build`), отладочная сборка `BuildDev` (читаемые имена функций в ошибках браузера). |

### Где что настраивать (Inspector)

- **Fighter**: здоровье, скорость, урон и дальность ударов, «можно пригнуться» / «сбивает с ног», блок, шкала супера, название и урон супера, портреты, голоса.
- **Sprite Frame Player**: клипы, FPS, `Hit Frame` (заполняет кнопка настройки — руками обычно не нужно).
- **Fighter AI**: `Aggression`, `Block Chance`, `Duck Chance`, `Kick Chance`, `Super Chance`, темп решений.
- **RoundManager**: `Rounds To Win`, `Round Time`, темп баннеров, замедление, тексты итогов.
- **Sound Manager**: громкость музыки и каждого сигнала, вариация тона, шанс «вякнуть».
- **ArenaBackground**: `Brightness`, линия пола на картинке и на экране, размер камеры на ПК/телефоне.

## 3. Ассеты и пайплайн

### Структура папок

```
SourceArt/          исходники из AI-генераций (Unity их не видит, git хранит) — см. SourceArt/README.md
  Murzik/, Belchik/   листы анимаций *_sheet.png
  Shared/             блок и присед — оба кота на одном листе
  UI/                 портреты, рамки, логотипы, раунды, экран итогов, лого игры
  Audio/              исходные звуки и треки
  Concept/            заставка-концепт
Tools/slice_sprites.py  нарезка листов в кадры
Assets/Art/<Кот>/      нарезанные кадры 640×512 (супер — 1024×512), лапы на одной линии, все лицом ВПРАВО
Assets/Art/UI/         интерфейс (обрезан, ≤1024 px)
Assets/Audio/          обработанные звуки (моно, без тишины) и music.ogg
Assets/Resources/Fonts/ шрифт Russo One (OFL) + лицензия
Builds/                сборки (не в git)
docs/                  эта документация и план оптимизации
```

### Графика: от генерации до игры

```
AI-генерация листа → SourceArt/<Кот>/<анимация>_sheet.png
  → python Tools/slice_sprites.py murzik|belchik
  → Assets/Art/<Кот>/<кот>_<анимация>_NN.png
  → Unity: Cat Fighter → Настроить бойцов → Ctrl+S
```

Что делает `slice_sprites.py` (настройки листов — словарь `CHARACTERS` в начале файла):
1. чистит почти прозрачный мусор (alpha < 10);
2. находит «острова» пикселей; коты — крупные (≥ ⅓ самого большого), мелочь — эффекты (приклеиваются к ближайшему коту) или подписи (выкидываются);
3. разделяет слипшиеся кадры: `split` (эрозия + ближайшее «зерно») или `cut` (вертикальный разрез);
4. приводит лист к единому росту кота (400 px по первому кадру, или `scale_like` — масштаб другой анимации);
5. зеркалит, если кот на листе смотрит влево (`flip`);
6. кладёт кадр на холст 640×512 (или `canvas_w`) лапами на одну линию; то, что не влезает, обрезается, а не сдвигает кота.

Анимации: `idle`, `punch` (01–06 правая, 07–08 левая), `kick`, `hit` (01–08; `hit_light` и `ko` собираются из него кодом), `walk` (6), `super` (8, удар на 5-м), `block`, `crouch`, `win` (необязательно, ещё не нарисована).

**Требования к новым листам для генератора:** один ряд, равные промежутки, кадры не касаются друг друга (эффекты тоже), кот лицом вправо, тот же масштаб, **прозрачный фон** (или однотонный тёмный — вырежем), без подписей или подписи не касаются лап. Готовые промпты — в истории проекта; ключевая фраза для фона: *«FULLY TRANSPARENT background, PNG with real alpha channel, do NOT draw a checkerboard»*.

### Звук

Файлы в `Assets/Audio` раскладываются по сигналам по началу имени: `whoosh`, `hit_light`, `hit_heavy`, `block`, `dodge`, `cat_hurt`, `ko`, `round`, `fight`, `win`, `lose`, `super`, `music`. Файлы с окончанием `_murzik` / `_belchik` — личные (голос боли `cat_hurt_<кот>`, клич `super_<кот>`) и подключаются к самим котам.
Обработка (ffmpeg): обрезка тишины, моно 44.1 кГц, выравнивание громкости; музыка — `.ogg`, без тишины в конце (ровный повтор).

Лицензии: шрифт Russo One — SIL OFL 1.1; крик Мурзика — Freesound #537990, CC0 (упомянут в README).

## 4. Сборка и публикация

### Собрать WebGL

**Unity должна быть закрыта** (один проект нельзя открыть дважды). Из корня проекта:

```bash
"/c/Program Files/Unity/Hub/Editor/6000.6.1f1/Editor/Unity.exe" -batchmode -nographics -quit -projectPath "D:/unity-projects/Cat Fighter" -executeMethod WebGLBuild.Build -logFile "D:/unity-projects/Cat Fighter/Logs/webgl_build.log"
```

Или из открытой Unity: **Cat Fighter → Собрать WebGL**. Результат — `Builds/WebGL`, размер и итог — в конце лога (строки `Cat Fighter:` и `Build Report`).
Сжатие Gzip + **Decompression Fallback** — сборка работает на любом статическом хостинге без настройки заголовков сервера.

### Выложить на GitHub Pages

Сайт раздаётся из ветки `gh-pages`, для неё есть отдельная рабочая папка (git worktree) `D:\unity-projects\cat-fighter-pages`:

```bash
P="/d/unity-projects/cat-fighter-pages"; git -C "$P" rm -rq . && cp -r Builds/WebGL/. "$P"/ && git -C "$P" add -A && git -C "$P" commit -m "Publish WebGL build" && git -C "$P" push
```

Через ~1 минуту обновление видно по ссылке (на ПК — Ctrl+F5, браузер кэширует файлы).

### Отладка ошибок в браузере

Обычная сборка показывает стек как `wasm-function[1518]`. Отладочная — с именами функций:
`-executeMethod WebGLBuild.BuildDev` → `Builds/WebGLDev`, запустить локально: `python -m http.server 8765` в этой папке и открыть `http://127.0.0.1:8765`.

## 5. Подводные камни (уже наступали)

| Симптом | Причина | Решение |
|---|---|---|
| Unity пишет «тип не найден», хотя файл есть | Unity «поймала» новый `.cs` в момент записи и закэшировала как не-скрипт | новые скрипты писать во временную папку и копировать целиком; лечится новым именем файла |
| Компонент не вешается из кода | MonoBehaviour должен лежать в файле со своим именем | один MonoBehaviour — один файл (`TouchButton`, `AdaptiveScaler`) |
| В браузере нет русского текста | встроенный шрифт Unity без кириллицы (в редакторе Windows подставляет системный) | `GameUI.Font` — Russo One из `Resources/Fonts` |
| Игра в браузере зависает на ROUND 1, «Maximum call stack size exceeded» | крупный текст (таймер 96 pt) не влезал в рамку → бесконечная перестройка текста | у всех `Text` — `HorizontalWrapMode.Overflow` / `VerticalWrapMode.Overflow` |
| На ПК в браузере показываются тач-кнопки | браузер на ПК тоже сообщает о «сенсорном вводе» | тач-кнопки только при `Application.isMobilePlatform` (или после реального касания) |
| Коты «висят в воздухе» на широком телефоне | фон центрировался и растягивался | `ArenaBackground` привязывает нарисованный пол к полу котов |
| После игры коты возвращаются в неправильной позе | в Sprite Renderer случайно попал кадр удара — он считается «стойкой» | кнопка настройки ставит `idle_01`, если там не кадр `_idle_` |
| Числовые поля новых элементов списка = 0 (FPS 0 → анимация зависла) | Unity не применяет значения по умолчанию из C# к новым элементам списка в Inspector | кнопка настройки заполняет всё сама; в коде защита от FPS = 0 |
| Кириллица портится в командах оболочки | кодировка heredoc в Git Bash | правки с русским текстом — через Python-файлы или редактор |

## 6. Дальнейшие планы

1. **Оптимизация размера сборки** (52 МБ → ~10 МБ) — [OPTIMIZATION_PLAN.md](OPTIMIZATION_PLAN.md).
2. **Свой экран загрузки** (WebGL-шаблон): логотип `SourceArt/UI/Logo/cat_fighter_logo.png` поверх заставки, полоска загрузки в стиле полоски здоровья, «CATS NEVER GIVE UP», игра на всё окно браузера.
3. **Рекламная версия** на 20–30 с: 1 раунд, простое управление тапом, финальная кнопка «ИГРАТЬ».
4. Необязательное: победные позы `win` (код готов), прыжок и удар в прыжке, цифры таймера картинками.
